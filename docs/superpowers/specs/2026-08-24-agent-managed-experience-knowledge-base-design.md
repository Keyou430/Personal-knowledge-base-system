# Agent 管理的经验沉淀知识库设计

## 目标

在现有个人知识库的问答流程上，增加由 Agent 管理的经验沉淀能力：用户从一条问答中主动触发沉淀，Agent 生成可编辑的结构化经验候选，本地检测精确重复和语义相似内容，用户确认后保存为可追踪、可版本化的经验卡片。

系统继续支持现有的多格式文档上传、分领域管理、文档浏览和 RAG 问答。大模型通过一个可配置的 OpenAI 兼容云端 API 调用。

## 范围

### 本期包含

- 在问答结果下主动触发“沉淀为经验”。
- 云端 Agent 从当前问题、回答和必要引用片段生成结构化候选。
- 候选字段：标题、问题/场景、核心结论、操作步骤、标签、来源引用。
- 用户编辑候选后再保存，禁止无确认自动入库。
- 只对结构化经验卡片做去重，不把原始文档片段直接当作重复对象。
- 精确哈希去重和本地语义相似检索。
- 相似时展示差异并提供“合并更新”“作为新经验保存”“放弃”。
- SQLite 保存经验、来源和版本；独立 Chroma 索引支持经验相似检索。
- 经验库浏览、搜索、详情、归档、恢复和索引重建。
- API、数据库和索引错误的可恢复处理。

### 本期不包含

- 多用户、权限系统和云端数据库。
- 后台文件夹监听、定时任务和无人值守自动写入。
- 跨领域自动合并。
- 全量文档覆盖检测。
- 多供应商路由或自动切换模型。
- 引入完整 Agent 工作流框架。

## 已确认的产品决策

1. 经验入口是问答过程中的“沉淀为经验”按钮。
2. Agent 先生成候选卡片，用户编辑并确认后才写入。
3. 去重范围仅为已保存的经验卡片。
4. 相似候选由用户决定合并、另存或放弃。
5. 云端接入采用单一可配置的 OpenAI 兼容接口，沿用现有 `LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL` 配置。
6. 只有用户主动点击沉淀时，才发送当前问答和必要引用片段；默认不后台上传。
7. 保留 Streamlit、现有文档存储和 Chroma RAG 基础，采用增量分层改造。

## 架构

```text
Streamlit 问答页面
    |
    v
经验沉淀服务（候选生成、校验、去重、审核动作）
    |                    \
    v                     v
云端 Agent API       SQLite 经验库
                          |
                          v
                    独立经验 Chroma 索引

现有文档上传 / 文档 Chroma / RAG 问答继续独立运行
```

### 模块职责

- `app.py`：渲染页面、表单和审核交互；通过服务接口调用业务逻辑，不直接拼接 Agent 提示词或操作 SQLite。
- `core/agent.py`：封装 OpenAI 兼容客户端、结构化输出、超时、有限重试和错误分类。
- `core/experience_pipeline.py`：编排“从问答生成候选 → 校验 → 去重 → 保存/合并”的显式流程。
- `core/experience_store.py`：负责 SQLite 初始化、查询、事务、版本快照、归档和恢复。
- `core/experience_index.py`：负责经验卡片的独立 Chroma collection、相似检索、增删和重建。
- `core/domains.py`：承载领域目录、领域列表、删除和原始文件列表等轻量文件系统操作。
- `core/retriever.py`：继续负责原始文档向量库和文档语义检索；不再承担领域文件系统职责。
- `core/generator.py`：继续负责问答生成；与 `core/agent.py` 共享 API 客户端配置，但保持问答和沉淀提示词隔离。

## 重点重构

这是有边界的分层重构，不是整体重写：

1. 从 `core/retriever.py` 拆出领域文件系统逻辑到 `core/domains.py`，保留必要的兼容包装，避免破坏现有调用。
2. 从 `app.py` 移除模块级重型导入，loader、splitter、retriever 和 generator 在实际功能边界按需导入，延迟初始化 Embedding 和 Chroma。
3. 把经验业务从 Streamlit 函数中移出，避免 UI 状态和持久化逻辑相互耦合。
4. 经验索引使用独立路径和 collection，避免经验卡片与原始文档 chunk 混合检索。
5. SQLite 作为经验事实来源，Chroma 作为可重建的检索投影；删除或修改时以数据库事务结果为准。

## 数据模型

### `experiences`

- `id`：稳定的 UUID 主键。
- `title`：经验标题。
- `scenario`：问题或适用场景。
- `conclusion`：核心结论。
- `steps_json`：操作步骤数组的 JSON 文本。
- `tags_json`：标签数组的 JSON 文本。
- `status`：`active` 或 `archived`。
- `content_hash`：规范化标题、场景、结论和步骤后的精确去重哈希。
- `created_at`、`updated_at`：UTC 时间戳。

### `experience_sources`

- `id`、`experience_id`：来源记录标识和关联经验。
- `question`：触发沉淀的问题。
- `answer_excerpt`：回答摘要或截断后的回答。
- `references_json`：文档路径、页码、片段摘要等引用信息。
- `created_at`：来源建立时间。

### `experience_versions`

- `id`、`experience_id`、`version`：版本标识。
- `snapshot_json`：保存当时完整卡片内容的 JSON 快照。
- `change_type`：`created`、`edited`、`merged`、`restored`。
- `created_at`：版本创建时间。

候选卡片在用户确认前只保存在 Streamlit session state；API 失败、校验失败或用户返回编辑时不得丢失候选内容。

## Agent 与数据流

1. 问答完成后，系统为该条问答保存稳定 ID、问题、回答和引用摘要。
2. 用户点击“沉淀为经验”后，构造最小云端 payload：问题、回答、必要引用片段和输出字段约束。
3. Agent 返回 JSON；系统验证必填字段、数组类型和最大长度，拒绝无法解析或明显为空的结果。
4. UI 展示候选编辑表单，用户确认后进入本地去重。
5. 去重先计算规范化内容哈希；哈希相同则直接标记精确重复。
6. 哈希不同则查询经验 Chroma，返回 Top-N 相似卡片及可配置相似度阈值。
7. 系统对候选与相似卡片做本地字段差异摘要，不为去重自动追加云端调用。
8. 用户选择保存新卡片、合并更新或放弃。
9. 保存/合并在 SQLite 事务中完成并写入版本快照；成功后更新经验索引。
10. 索引更新失败时记录 `index_pending`，经验仍可在经验库中查看并可手动重建索引。

## 合并规则

- 合并前必须展示字段级差异和目标卡片的当前版本。
- 用户确认后，标题、场景、结论和步骤按确认后的候选内容写入。
- 标签取两张卡片的去重并集。
- 原内容写入 `experience_versions`，不能静默覆盖。
- 默认不把旧卡片再次发送云端；如未来增加云端合并开关，必须单独显示发送范围并取得明确确认。

## 界面设计

- 问答历史的每条回答下显示“沉淀为经验”。
- 沉淀中显示处理中、候选编辑、重复审核、保存成功和失败可重试状态。
- 候选表单始终显示引用来源，用户可删除不必要的来源。
- 重复审核显示相似度、标题、核心结论和差异摘要，提供三个明确动作。
- 新增“经验库”视图，支持标题/标签/场景搜索、详情查看、版本历史、归档/恢复和索引重建。
- 不增加后台自动写入；所有云端调用和写入动作都由用户点击触发。

## 云端 API 与隐私

- 沿用现有 OpenAI 兼容配置，不绑定单一供应商。
- Agent 请求使用独立系统提示词和结构化 JSON 输出约束。
- 设置连接超时、有限重试和最大输入长度，避免发送整个知识库。
- 日志只记录时间、模型、耗时、token 用量和错误类型；不记录 API Key 或默认完整正文。
- API 调用发生前在 UI 明确提示将发送当前问题、回答和选定引用片段。
- 去重和相似检索尽量在本地完成。

## 错误处理

- 未配置 API Key、网络超时、限流和服务端错误：显示可理解的错误并保留候选/问答状态。
- JSON 解析或字段校验失败：执行一次受限修复请求，仍失败则转为手动编辑。
- SQLite 异常：事务回滚，不产生半条经验。
- Chroma 不可用：经验仍保存到 SQLite，显示索引待重建状态。
- 重复点击：使用问答 ID 加内容哈希实现幂等，避免重复生成或重复入库。

## 测试与验收

### 自动化测试

- Agent JSON 解析、字段校验和错误分类。
- 文本规范化、精确哈希和重复提交幂等性。
- 语义候选排序、阈值和无候选分支。
- 新建、编辑、合并、另存、放弃、归档和恢复。
- 版本快照、事务回滚和索引待重建状态。
- Mock 云端 API 的成功、空响应、格式错误、超时和限流。
- Streamlit 问答历史与沉淀按钮的稳定 ID 绑定。
- 导入 `app.py` 时不初始化 Embedding 或 Chroma，首次功能调用时才加载。

### 验收标准

1. 用户能从一条问答生成候选经验并编辑后保存。
2. 相同或相似经验不会在没有提示的情况下直接新增。
3. 合并前能看到差异，合并后可从版本历史恢复旧内容。
4. 云端调用仅发生在用户主动沉淀时，发送范围可见。
5. API 或索引异常不会丢失问答、候选或已保存经验。
6. 现有文档上传、领域管理、RAG 问答功能继续可用。
7. 应用启动不再因为 Embedding/Chroma 初始化而阻塞。
